# DESIGN.md — «Моя библиотека»

Версия: 1.0  
Дата: 8 октября 2026 года  
Основной экран: каталог домашней библиотеки

## 1. Назначение документа

Спецификация описывает визуальную систему и поведение сайта по созданному макету «Моя библиотека». Она предназначена для дизайнера и разработчика, которые будут превращать изображение в рабочий интерфейс.

Референс — настольный экран размером **1513 × 1039 px**: слева постоянная навигация, справа поиск, фильтры и восемь книг в сетке из четырёх колонок. Референс создан как растровое изображение; метаданных исходных шрифтов и компонентов у него нет.

Размеры, цвета и интервалы ниже — нормализованные значения для реализации, выбранные по изображению. Небольшую неоднородность обложек, бледность отдельных подписей и неточности нарисованных иконок воспроизводить не требуется. При расхождении приоритет имеют читаемость, доступность и согласованность компонентов.

**Показано на макете:** настольная компоновка, состав навигации, панель управления, карточки книг, цвета статусов и места хранения.

**Определено этим документом дополнительно:** конкретные файлы шрифтов для вёрстки, адаптивность, раскрытые меню, формы, состояния загрузки и ошибок, клавиатурное управление. Это проектные решения для реализации, а не дополнительные экраны, уже существующие в референсе.

Документ описывает интерфейс. Выбор фреймворка, базы данных, серверной архитектуры и внешних книжных сервисов остаётся за рамками этой спецификации.

## 2. Продукт и основные задачи

«Моя библиотека» помогает владельцу домашней коллекции ответить на четыре вопроса:

1. Есть ли у меня эта книга?
2. Где она стоит или у кого сейчас находится?
3. Что я читаю, уже прочитал и хочу прочитать?
4. Как добавить новую книгу и назначить ей место?

Основная единица каталога — запись о физическом экземпляре книги. Два экземпляра одного названия могут иметь разные места хранения и разные состояния выдачи. Счётчик книг отражает число экземпляров, а не уникальных названий.

Ключевые сценарии первого экрана: поиск, просмотр коллекции, фильтрация, переход к сведениям о книге и добавление экземпляра.

## 3. Визуальное направление

**Характер:** спокойный, домашний, книжный, аккуратный.

Впечатление создают четыре элемента:

- тёплый светлый фон с едва заметной бумажной фактурой;
- крупная книжная антиква в названии сервиса и заголовке страницы;
- тёмно-зелёные активные элементы;
- выразительные обложки, занимающие основную часть каталога.

Интерфейсные элементы должны оставаться визуально спокойными. Разнообразие цвета и иллюстрации сосредоточено в обложках.

Карточка книги лежит непосредственно на общем фоне. У неё нет отдельной белой подложки, общей рамки или тени вокруг всего содержимого. Небольшая тень принадлежит обложке.

Не добавлять крупный рекламный блок над каталогом, цены, корзину, декоративные градиенты или статистические виджеты: они меняют назначение и композицию этого экрана.

## 4. Компоновка настольного экрана

### 4.1. Общая структура

Страница состоит из двух областей: боковой навигации и основной области каталога.

| Область | Значение для большого настольного экрана |
| --- | --- |
| Боковая панель | 312 px |
| Разделитель панели | 1 px, декоративный цвет линии |
| Горизонтальные отступы основной области | 40 px |
| Верхний отступ основной области | 16 px; допускается оптическая корректировка до 24 px |
| Нижний отступ основной области | 40 px |
| Максимальная ширина содержимого каталога | 1280 px без учёта внешних отступов |
| Колонки каталога | 4 равные колонки |
| Интервал между колонками | 56 px |
| Интервал между рядами карточек | 32 px после самого высокого блока в ряду |

На широких экранах содержимое каталога центрируется внутри основной области и сохраняет четыре колонки. Боковая панель остаётся у левого края окна.

Основная страница прокручивается по вертикали. Боковая панель закреплена в пределах высоты окна; если её содержимое не помещается, оно получает собственную вертикальную прокрутку. Горизонтальная прокрутка всей страницы не допускается.

### 4.2. Порядок элементов основной области

1. Заголовок «Мои книги» и действие «Добавить книгу».
2. Подзаголовок со счётчиками.
3. Поле поиска на всю доступную ширину.
4. Панель фильтров; справа сортировка и переключение вида.
5. Каталог книг.

В настольной компоновке кнопка добавления находится справа от группы заголовка, у верхнего края. Поиск начинается ниже всей группы заголовка. Между поиском и панелью фильтров — 16 px; между панелью фильтров и каталогом — 20–24 px.

Заголовок не обрезается. При недостатке места группа заголовка и кнопка перестраиваются на отдельные строки.

### 5.2. Фактура фона

Использовать очень мелкое равномерное зерно поверх основного цвета. Фактура декоративная: не перехватывает события, не участвует в доступном имени элементов и не снижает читаемость текста. Начальный ориентир непрозрачности слоя — 2–3% при условии, что сам ресурс имеет слабый контраст.

Контраст проверять после применения текстуры. Под мелкими подписями, полями и метками допустим ровный цвет без зерна. При отсутствии подходящего ресурса использовать чистый фон из палитры.

## 6. Типографика

Для реализации выбрать **Lora** для крупных заголовков и названия сервиса, **Inter** для управления и метаданных. Lora сохраняет книжный характер фактического изображения; Inter обеспечивает спокойный ритм коротких подписей.

Это выбранные гарнитуры для вёрстки, а не утверждение о том, какими файлами шрифтов сгенерированы пиксели референса. Lora поддерживает кириллицу и распространяется по SIL OFL 1.1; Inter также имеет открытую лицензию SIL OFL 1.1. Источники: [Lora][lora-source], [Inter][inter-source]. Использовать сборки с русскими символами, а не только латинское подмножество.

| Элемент | Шрифт | Размер / интерлиньяж | Насыщенность |
| --- | --- | --- | --- |
| «Мои книги», большой экран | Lora | 64 / 72 px | 500 |
| Заголовок, средний экран | Lora | 48 / 56 px | 500 |
| Заголовок, телефон | Lora | 36 / 42 px | 500 |
| «Моя библиотека» в панели | Lora | 28 / 36 px | 500 |
| Название книги | Inter | 18 / 24 px | 600 |
| Автор | Inter | 16 / 22 px | 400 |
| Навигация | Inter | 17 / 24 px | 400; выбранный пункт — 500 |
| Поиск, кнопки и фильтры | Inter | 16 / 24 px | 400; основная кнопка — 500 |
| Счётчики и местоположение | Inter | 14 / 20 px | 400 |
| Метка статуса | Inter | 14 / 20 px | 500 |
| «МОИ ПОЛКИ» | Inter | 13 / 18 px | 500 |

У подписи группы навигации использовать верхний регистр и `letter-spacing: 0.08em`. У основного текста оставлять нормальный межбуквенный интервал. У крупного заголовка допустимо `-0.02em` после проверки кириллических сочетаний.

Размеры текста задавать в `rem`, сохраняя указанные пропорции при базовом размере 16 px. Не отключать пользовательское масштабирование. Подключать только используемые начертания либо соответствующий диапазон вариативного файла; отображать резервный шрифт во время загрузки.

Названия книг показывать до двух строк. Авторы также могут занимать две строки. Длинные значения не должны расширять колонку. Полные название и автор доступны на экране книги; доступное имя ссылки содержит полный текст даже при визуальном сокращении.

Типографика внутри обложки относится к изображению издания и не заменяется интерфейсными шрифтами.

## 7. Боковая навигация

### 7.1. Состав

Вверху — контурная иконка раскрытой книги и текст «Моя библиотека».

| Пункт | Смысл | Счётчик |
| --- | --- | --- |
| Все книги | Вся коллекция | Число экземпляров |
| Читаю сейчас | Статус чтения «Читаю» | В исходном макете не показан |
| Хочу прочитать | Статус чтения «В планах» | В исходном макете не показан |
| Прочитано | Статус чтения «Прочитано» | В исходном макете не показан |
| У друзей | Экземпляры с активной выдачей | Число выданных экземпляров |

После разделителя: подпись «МОИ ПОЛКИ», группы «Гостиная», «Кабинет», «Спальня» и действие «Новая полка».

Названия комнат в панели — группы мест хранения. Внутри комнаты может быть несколько физических полок. Счётчик полок в заголовке учитывает отдельные полки, а не комнаты.

Для реализации предусмотреть раскрытие комнаты во вложенный список полок. Выбор названия комнаты охватывает все её полки; выбор вложенной полки сужает домашнее место до неё. Оба действия синхронизируются с фильтром «Полка». В исходном состоянии группы свёрнуты. Кнопка раскрытия имеет отдельную доступную подпись и не подменяет действие выбора комнаты.

Счётчики боковой панели относятся ко всей коллекции и не уменьшаются из-за поискового запроса или дополнительных фильтров. Число текущих результатов показывается в основной области.

Внизу — круглый аватар владельца, подпись «Личная библиотека» и кнопка настроек. Нижняя группа не должна перекрывать навигацию при небольшой высоте окна.

### 7.2. Размеры и состояния

- Внутренний горизонтальный отступ панели — 12 px для оболочки навигации.
- Высота строки — 56 px; внутренний горизонтальный отступ — 20 px.
- Иконка — 24 px; расстояние от иконки до текста — 20 px.
- Счётчик выравнивается по правому краю строки и использует табличные цифры.
- Выбранный пункт: `--color-primary`, белые текст и иконка, радиус 10 px.
- Обычный пункт: прозрачный фон и основной цвет текста.
- Наведение: `--color-hover-surface`.
- Клавиатурный фокус: отдельная видимая обводка; он не совпадает по смыслу с выбранным разделом.

Состояние выбранного раздела обозначается программно, например `aria-current` для навигационной ссылки. Декоративные иконки внутри подписанного пункта не повторяют его название для скринридера.

## 8. Панель управления каталогом

### 8.1. Заголовок и счётчики

Начальное название — «Мои книги». Подзаголовок: «128 книг · 7 полок» в иллюстративном состоянии референса.

В рабочем интерфейсе числа вычисляются по данным. После применения ограничений рядом с заголовком показывать результат, например «Найдено 12 из 128 книг». Использовать правильные русские формы: «1 книга», «2 книги», «5 книг»; «1 полка», «2 полки», «7 полок».

### 8.2. Основное действие

Кнопка «Добавить книгу» содержит иконку плюса слева, фон `--color-primary`, белую подпись и радиус 8 px. Высота — 52 px, горизонтальный отступ — 24 px, промежуток между иконкой и текстом — 12 px.

Кнопка открывает форму добавления, описанную в разделе 12. На текущем экране это единственное основное действие с крупной сплошной заливкой.

### 8.3. Поиск

Поле высотой 48 px занимает всю ширину основной области. Слева находится иконка поиска 20 px. Подсказка: «Название, автор или ISBN». Поле имеет доступную подпись «Поиск по библиотеке», отдельную от подсказки.

Предлагаемое поведение:

- искать одновременно по названию, автору и ISBN;
- не учитывать регистр; считать «е» и «ё» эквивалентными при поиске;
- игнорировать пробелы и дефисы в запросе ISBN;
- обновлять результат через 250 мс после последнего ввода; Enter применяет запрос сразу;
- показывать кнопку очистки, когда поле заполнено;
- при очистке поиска сохранять выбранные фильтры и сортировку;
- не переводить клавиатурный фокус в результаты при каждом обновлении.

### 8.4. Фильтры

Слева находятся три контурные кнопки: «Жанр», «Статус», «Полка». Высота — 44 px, радиус — 8 px, внутренние горизонтальные отступы — 14–16 px. Между кнопками — 12 px. Справа каждой подписи — небольшой шеврон.

Для первой реализации каждый фильтр выбирает одно значение. Предусмотреть значение «Все» и явный сброс. Названия жанров и полок формируются по данным коллекции.

После выбора значение видно в подписи кнопки либо отдельной метке под панелью. При наличии активных ограничений появляется действие «Сбросить фильтры». Оно сбрасывает жанр, статус, комнату/полку и ограничение «У друзей», сохраняя поисковую строку, сортировку и вид каталога. Отдельное действие «Сбросить поиск и фильтры» очищает весь набор ограничений.

Поиск и разные фильтры применяются совместно. Навигационные пункты чтения и фильтр «Статус» управляют одним значением: выбор в одном месте сразу отражается в другом. Пункт «У друзей» задаёт дополнительное условие выдачи и может сочетаться со статусом чтения. Все действующие ограничения должны быть видны.

Правила переходов бокового меню:

- «Все книги» снимает ограничения чтения и выдачи, сохраняя поиск, жанр и домашнее место.
- Выбор пункта чтения назначает соответствующий статус и снимает ограничение выдачи; остальные условия сохраняются.
- «У друзей» включает ограничение выдачи и первоначально снимает статус чтения. После этого фильтром «Статус» можно выбрать, например, только прочитанные выданные книги.
- При активном условии выдачи выделяется «У друзей», а чтение отражается в фильтре. Без условия выдачи выделяется соответствующий пункт чтения либо «Все книги», если отдельного пункта для выбранного статуса нет.

Фильтр «Полка» относится к закреплённому домашнему месту, даже если книга временно выдана. В меню можно использовать уточняющую подпись «Домашнее место хранения».

### 8.5. Сортировка и вид

Справа находится сортировка «Недавно добавлены»: новые записи показываются первыми. Дополнительные предлагаемые варианты — «По названию: А–Я» и «По автору: А–Я».

Рядом — две кнопки 44 × 44 px с иконками сетки и списка. Выбранная кнопка имеет основной зелёный фон. Доступные названия: «Показать сеткой» и «Показать списком»; выбранное состояние передаётся программно, например через `aria-pressed`.

Переключение вида сохраняет поиск, фильтры, сортировку и состав выдачи. При возвращении со страницы книги восстанавливаются условия просмотра и положение в каталоге.

## 9. Карточка книги

### 9.1. Структура и ритм

Порядок внутри карточки:

1. Обложка.
2. Название.
3. Автор.
4. Компактная метка состояния.
5. Домашнее место хранения с контурной иконкой полки.

| Интервал | Значение |
| --- | --- |
| Обложка → название | 12 px |
| Название → автор | 4 px |
| Автор → метка | 8 px |
| Метка → место хранения | 8 px |

Контейнеры обложек одного ряда имеют общие верхнюю и нижнюю границы; изображения внутри выровнены по нижней границе. Текстовые блоки карточек в ряду выравниваются по наиболее высокому содержимому. Если название или автор переносятся, высота ряда увеличивается. Не уменьшать текст ради принудительного размещения двух рядов в высоте окна.

Обложка и название открывают одну страницу книги и образуют один фокусируемый элемент. Автор, статус и место хранения — текстовые сведения. Метка статуса не выглядит кнопкой и не получает курсор действия.

### 9.2. Обложки

Использовать одинаковый контейнер с соотношением сторон **4:5**, близким к референсу. Внутри него изображение показывается через `object-fit: contain` с выравниванием по нижней границе. Не растягивать обложку и не обрезать её название. Если пропорции изданий различаются, сохранять их внутри единого слота.

Радиус обложки — 4 px. Тень — мягкая и короткая: `--shadow-cover`. Если ресурс уже содержит корешок и тень, не накладывать второй сильный объём. Тень у изображения с прозрачными краями должна следовать силуэту книги.

В референсе обложки иллюстративные: терракотовая, кремовая, охристая, хвойная, синяя, бирюзовая, ботаническая и чёрно-красная. Эта подборка задаёт разнообразие, но не ограничивает палитру реальных книг. Загруженные изображения показываются в исходных цветах.

При отсутствии обложки использовать нейтральный бумажный слот того же размера с тонким книжным знаком и коротким названием. Ошибка загрузки изображения переводит карточку в это же состояние без изменения геометрии.

Если название уже включено в доступное имя ссылки, изображение обложки внутри неё может иметь пустой `alt`, чтобы не дублировать текст. Самостоятельное информативное изображение получает осмысленный `alt`.

### 9.3. Метки и независимые состояния

**Чтение, выдача и домашняя полка — независимые характеристики.** Выдача экземпляра не меняет статус чтения и не стирает его постоянное место.

| Характеристика | Значения / пример | Представление |
| --- | --- | --- |
| Статус чтения | Читаю | Светло-шалфейная метка |
| Статус чтения | Прочитано | Светло-шалфейная метка |
| Статус чтения | В планах | Светло-охристая метка |
| Статус чтения | Без статуса | Нейтральная метка; дополнительное состояние для новых записей |
| Выдача | У Анны | Светло-терракотовая метка |
| Домашняя полка | Спальня · полка 2 | Отдельная текстовая строка |

Метка имеет минимальную высоту 28 px, горизонтальные отступы 12 px и капсульную форму. Цвет текста — `--color-status-text`. «Читаю» и «Прочитано» намеренно близки по цвету, как в референсе; смысл передаётся подписью.

В компактной карточке активная выдача имеет приоритет в единственном слоте метки: показывать «У Анны». Статус чтения при этом остаётся сохранённым, участвует в фильтрации и виден в подробных сведениях. После возврата книги снова показывается метка чтения.

Строка полки у выданной книги означает место, куда её нужно вернуть. На подробном экране явно разделять «Сейчас у Анны» и «Место дома: Спальня · полка 2». Если полка не назначена, выводить «Место не указано».

### 9.4. Наведение и фокус

При наведении разрешены небольшое усиление тени обложки и изменение оформления ссылки названия. Карточка сохраняет положение и размеры. Не использовать наклоны, увеличение всей карточки или подъём, сдвигающий визуальный ритм.

Фокус ссылки хорошо виден вокруг области перехода. Все сведения и действия остаются доступны без наведения.

## 10. Представление списком

Список не показан в референсе; ниже задано поведение уже изображённого переключателя.

На большом экране одна строка содержит миниатюру обложки, название и автора, состояние и домашнюю полку. Между строками — тонкий декоративный разделитель. Отдельных карточек с белой подложкой не требуется.

Миниатюра занимает слот 48 × 60 px; вертикальный внутренний отступ строки — 12 px. Название, автор и состояния используют те же шрифты и цвета, что сетка. На узком экране метаданные переносятся под название, образуя компактный вертикальный блок справа от миниатюры.

Чтение и выдача могут отображаться двумя подписанными метками, когда ширины достаточно. На узком экране действует тот же приоритет выдачи, что в сетке. Список показывает те же экземпляры в том же порядке и не сбрасывает условия поиска.

Мобильная и промежуточная компоновки являются дополнением к настольному референсу. Точки перехода указаны в CSS-пикселях ширины окна.

### 11.1. Навигация на узком экране

Ниже 1024 px постоянная панель заменяется компактной верхней строкой с кнопкой меню и названием «Моя библиотека». Нажатие открывает левую выдвижную панель шириной `min(312px, 88vw)` с тем же содержимым.

Панель имеет кнопку закрытия, удерживает фокус внутри при открытии и закрывается по Escape. После закрытия фокус возвращается к кнопке меню. Выбор раздела закрывает панель и переводит пользователя к обновлённому каталогу.

### 11.2. Управление на телефоне

- Сохранять порядок: заголовок, основное действие, поиск, фильтры, управление выдачей, книги.
- Кнопку «Добавить книгу» переносить под заголовок; подпись сохранять полностью.
- Поиск занимает отдельную строку и всю доступную ширину.
- Фильтры свободно переносятся; кнопки не обрезаются и не вызывают горизонтальную прокрутку.
- Сортировка и переключатель вида размещаются следующей строкой при нехватке места.
- Подписи внутри полей сохраняют размер 16 px.
- На самом узком экране обложка в одноколоночной сетке ограничивается шириной 280 px; карточка и текст остаются выровнены по левому краю.

При длинных названиях комнат, авторов и книг приоритет имеет перенос текста. Ни один существенный смысл не должен быть доступен только через наведение мыши.

## 12. Формы и раскрытые элементы

Эти состояния не нарисованы в референсе; они используют ту же палитру, отступы и типографику.

### 12.1. Добавление книги

На настольном экране открывается диалог «Добавить книгу» шириной до 560 px. На телефоне он занимает доступную ширину с полями по 16 px. Содержимое формы прокручивается при открытой экранной клавиатуре.

Минимальный состав: название, автор, обложка, ISBN, жанр, статус чтения, комната и полка. Обязательно только название; остальные сведения можно внести позднее. Для нового экземпляра не назначать произвольную комнату, автора или статус чтения.

Поля имеют видимые подписи, высоту не менее 48 px и ясные сообщения об ошибках рядом с соответствующим полем. Действия — «Добавить книгу» и «Отмена». Во время сохранения основное действие показывает «Добавляем…» и не допускает повторной отправки.

После успеха: закрыть диалог, обновить каталог и счётчики, показать сообщение «Книга добавлена». Если действующие ограничения скрывают экземпляр, уточнить: «Книга добавлена, но скрыта текущими фильтрами» и предложить «Показать книгу». При ошибке сохранить все введённые значения.

### 12.2. Новая полка

Действие открывает компактный диалог с полями «Комната» и «Название полки». Комнату можно выбрать из существующих или указать новую. Название полки допускает привычные владельцу обозначения: «полка 2», «верхняя», «у окна».

После сохранения новая полка появляется в навигации и фильтре. Счётчик полок обновляется по фактическим данным.

### 12.3. Меню и подробности книги

Меню фильтров и сортировки имеют фон `--color-surface`, тонкую границу, радиус 8 px и `--shadow-popover`. Текущий выбор виден по отметке и тексту. Меню не выходит за край окна; длинный список прокручивается внутри.

Переход по книге открывает экран полных сведений. Там доступны полное название, автор, домашнее место, статус чтения, информация о выдаче и действия изменения этих данных. Подробный экран сохраняет визуальную систему документа; отдельная композиция этого экрана здесь не фиксируется.

| Обновление результатов | Текущий каталог остаётся видимым; небольшой индикатор рядом со счётчиком | Поиск сохраняет фокус |
| Пустая библиотека | «Здесь появятся ваши книги» и короткая поясняющая подпись | «Добавить первую книгу» |

При ошибке обновления уже загруженной выдачи оставлять её на экране и сообщать, что обновление не удалось. Не подменять такую ошибку пустым результатом.

Приоритет пустых состояний: действительно пустая коллекция → пустая библиотека; пустая выдача с дополнительным поиском или фильтрами → «Книги не найдены»; раздел без дополнительных ограничений → сообщение о самом разделе. «Все книги дома» допустимо только тогда, когда в коллекции нет активных выдач, а не когда выданные книги исключены текущими условиями поиска. Тот же принцип применяется к разделам чтения.

Скелетоны не должны имитировать реальные названия. Появление обложек не сдвигает соседние карточки. Подтверждения действий показываются спокойно, не перекрывают каталог и доступны скринридеру.

## 14. Иконки, движение и доступность

### 14.1. Иконки и переходы

Использовать один согласованный набор контурных SVG-иконок. Основные размеры — 20 и 24 px, толщина линий — около 1,75 px. Иконка раскрытой книги в логотипе может быть 36 px. Emoji не использовать как замену интерфейсным иконкам.

Переходы цвета, фона и тени — 150 мс; появление диалога или панели — до 200 мс. Поддерживать `prefers-reduced-motion`: убирать движение и пульсацию, сохраняя мгновенную смену состояния. Контент не должен подпрыгивать после загрузки шрифтов или обложек.

### 14.2. Доступность

Цель реализации — доступность ключевых сценариев с клавиатуры, скринридером и при увеличении интерфейса. Соответствие WCAG оценивается на рабочем сайте, а не на растровом макете.

- Язык страницы — русский (`lang="ru"`).
- Использовать семантические области навигации, основного содержимого и формы поиска; на странице один основной `h1`.
- Добавить ссылку пропуска навигации «Перейти к книгам».
- Все действия доступны с клавиатуры; порядок фокуса следует визуальному порядку.
- Видимый фокус — обводка 3 px с отступом 3 px. На тёмном выбранном элементе использовать светлую внутреннюю границу и контрастную внешнюю обводку.
- У кнопок без текста есть доступные названия. Декоративные пиктограммы скрыты от скринридера.
- Метки состояния передают смысл текстом, дополнительно к цвету.
- Поиск и поля формы имеют отдельные подписи. Ошибка связана с полем программно.
- Диалоги получают заголовок, удерживают фокус, закрываются по Escape и возвращают фокус к инициатору.
- Количество найденных книг и результаты действий объявляются через спокойную область уведомлений; не озвучивать каждую введённую букву.
- При увеличении текста до 200% и на ширине 320 CSS px не теряются действия и сведения; каталог перестраивается без горизонтального скролла страницы.

Для обычного текста принимать минимальный контраст **4,5:1**. WCAG допускает **3:1** для крупного текста; в данной палитре заголовки существенно контрастнее. См. [W3C: Contrast Minimum][wcag-contrast].

Проектный минимум области нажатия — **44 × 44 CSS px** для всех основных элементов управления. Это выбранный запас удобства; не следует выдавать его за буквальный порог WCAG 2.2 AA, где критерий 2.5.8 использует 24 × 24 CSS px с оговорёнными исключениями. См. [W3C: Target Size Minimum][wcag-target].

Расчётные значения для непрозрачных цветов из раздела 5, без текстуры:

| Пара | Контраст |
| --- | --- |
| Основной текст / фон страницы | 11,99:1 |
| Вторичный текст / фон страницы | 4,80:1 |
| Подсказка / фон поля | 4,73:1 |
| Белый текст / основной зелёный | 8,56:1 |
| Граница элемента / фон страницы | 3,04:1 |
| Текст метки / шалфейный фон | не менее 9,07:1 |
| Текст метки / охристый фон | 9,12:1 |
| Текст метки / терракотовый фон | 7,54:1 |

Декоративный разделитель `--color-line` не заменяет границу интерактивного поля. После добавления текстуры, прозрачности и состояний фокуса итоговые сочетания проверяются повторно.

## 16. Критерии готовности реализации

- [ ] На большом настольном экране сохранены левая панель, крупный книжный заголовок и четыре колонки обложек.
- [ ] У карточек нет общей подложки и общей тени; объём создают обложки.
- [ ] Все контейнеры обложек имеют единые пропорции; изображения не растянуты и не обрезают название.
- [ ] Длинные русские названия и авторы не ломают сетку и остаются доступными полностью.
- [ ] Основной цвет, шрифты, размеры, радиусы и интервалы берутся из общих токенов.
- [ ] Чтение, выдача и домашнее место учитываются раздельно; возврат книги не меняет статус чтения.
- [ ] Навигация и фильтры не создают скрытых противоречащих ограничений.
- [ ] Поиск, сортировка и переключение вида сохраняют согласованную выдачу.
- [ ] Счётчики вычисляются по данным; демонстрационные числа не зашиты в интерфейс.
- [ ] Есть пустые состояния, отсутствие результатов, ошибки и резервная обложка.
- [ ] Добавление подтверждается только после успешного сохранения; ошибка не уничтожает введённые значения.
- [ ] Интерфейс работает с клавиатуры и видимым фокусом; диалоги возвращают фокус.
- [ ] На ширинах 320, 480, 768, 1024, 1280 и 1513 CSS px нет горизонтальной прокрутки страницы и перекрытия элементов.
- [ ] Контраст проверен на финальных фонах; текстура не делает подписи бледными.
- [ ] Кириллица, включая «Ёё», а также цифры, знак процента и ISBN отображаются выбранными шрифтами корректно.
