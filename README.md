# books.vitalik.dev — Каталог бумажных книг

Личный каталог бумажных книг, работающий как статический веб-сайт на **Astro** и управляемый с помощью ИИ.

---

## 🚀 Как добавлять книги по фотографиям

1. **Сделайте фотографии** ваших книг (обложки или корешки).
2. **Положите файлы фотографий** в папку `incoming_photos/` в корне проекта.
3. **Напишите агенту в чат**:
   > *"Я закинул фотографии в incoming_photos, обработай их"*
4. **ИИ агент сделает всё остальное**:
   - Распознает книги по фотографиям (название, автора, издательство, ISBN).
   - Найдет в интернете недостающие данные (год, жанры, аннотацию) и обложку в высоком разрешении.
   - Скачает обложку в `public/covers/`.
   - Создаст карточку книги в `src/content/books/<slug>.md`.
   - Перенесет обработанное фото в папку `processed_photos/`.

---

## 🛠 Локальный запуск и сборка

```bash
# Установка зависимостей (уже выполнена)
pnpm install

# Запуск локального сервера разработки (http://localhost:4321)
pnpm dev

# Сборка статического сайта для деплоя
pnpm build

# Проверка типов
pnpm check

# Предпросмотр сборки
pnpm preview
```

## 📁 Структура проекта

- `incoming_photos/` — папка для новых фотографий книг от вас.
- `processed_photos/` — архив обработанных фото.
- `src/content/books/` — база данных книг в формате Markdown (`.md` с YAML Frontmatter).
- `public/covers/` — качественные обложки книг.
- `scripts/book_scanner.py` — утилита для поиска метаданных и скачивания обложек.
- `.github/workflows/deploy.yml` — автоматический деплой на GitHub Pages при `git push`.
