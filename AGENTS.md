# Инструкции для агентов (AGENTS.md)

## Команды
- `pnpm dev` — запуск локального сервера разработки Astro (порт 4321)
- `pnpm build` — сборка статического сайта в папку `dist/`
- `pnpm check` — проверка типов Astro и TypeScript
- `python3 scripts/book_scanner.py` — утилита для поиска метаданных, скачивания обложек и добавления книг

## Архитектура и соглашения
- **Стек:** Astro (Content Layer API) + Preact (`@astrojs/preact`) + Tailwind CSS v4 (`@tailwindcss/vite`).
- **Иконки:** Использовать `@lucide/astro` (пакет `lucide-astro` устарел).
- **База данных книг:** Хранится в `src/content/books/<slug>.md`; схема Zod определена в `src/content.config.ts`.
- **Каталог книг:** В каталоге присутствуют только реальные книги пользователя (без демо-данных).
- **Терминология и ярлыки:** Категории книг называются «Ярлыки». Иконки ярлыков рендерятся через `TagIcon.astro`.
- **Навигация бокового меню (Sidebar):** Пункты в `Sidebar.astro` — это ссылки `<a>`. Со страниц книг клик по пунктам ведет в каталог на главную (`/` или `/?genre=<ярлык>`). Пункт «Все книги» визуально выбран только на главной странице при отсутствии выбранного ярлыка.
- **Слаги (slug):** Транслитерация латиницей в нижнем регистре: `<автор>-<название>` (например, `bulgakov-master-i-margarita`).
- **Обложки:** Сохраняются в `public/covers/<slug>.jpg`, в frontmatter указывается `/covers/<slug>.jpg` (заглушка по умолчанию: `/covers/default-book.svg`).
- **Пайплайн фотографий:** Новые фото книг помещаются в `incoming_photos/` (поддерживается как JPEG/PNG, так и HEIC) и перемещаются в `processed_photos/` после добавления в каталог. Исходные фотографии в `processed_photos/` бережно сохраняются навсегда (для архива и возможного использования в интерфейсе в будущем), ни в коем случае не удалять их!
- **Контроль качества обложек:** Обязательно визуально проверять скачанную обложку через `view_file` и сверять название/автора с исходным фото, чтобы исключить случайные обложки из товарных рекомендаций магазинов.
- **Особенности API:** Google Books API без ключа может возвращать ошибку 429 (Too Many Requests); в таком случае передавайте метаданные и URL обложки напрямую аргументами в `book_scanner.py` или используйте веб-поиск.
